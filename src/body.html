从符号到声音

每个碱基或氨基酸按原始顺序生成一个音符。MIDI 数字表示音高，数字越大，声音越高。

科学模式

采用 Seq2Music mapping v2 的固定音高与力度。每个符号占 0.3 拍，发声时长为间隔的 82%。BPM 调整时间，音色调整声音质感，原始音高保持不变。

DNA / RNA 中 G、C 的力度为 84，A、T、U 为 64，N 为 38。N 表示未知碱基。蛋白质力度按 Kyte–Doolittle 疏水性值映射；这些声音规则用于表达序列数据。

创作模式

可调整移调、C 调音阶、节奏间隔和摇摆。音阶吸附选择最近音高，等距时选择较低音。原始符号和基础音高保留在事件 CSV 中，可随时返回科学模式。

比较与导出

A / B 当前支持同类型、等长比较。严格对照固定科学映射、0.3 拍与统一正弦基础音色，保留各符号固有力度。双轨播放时 A 偏左、B 偏右；差异用边框、符号和数值共同标记。突变提示默认关闭；开启后仅对差异位点增加 20 力度（上限 120），并加入二次泛音。切换开关会停止当前播放。

MIDI 使用通用音符与速度，实际音色由播放器决定；WAV 保存当前合成音色。CSV 保留原始位置、基础值、输出值和参数；比较导出另含差异、原始力度与提示状态。选定范围导出时，时间从零开始。

“保存研究记录”保存上次导出的输入快照、参数、事件和文件 SHA-256；相同输入与参数的多种导出合并记录，修改后重新导出会建立新记录。记录需单独下载保存。
本版导出不含 Seq2Music 完整可逆载体协议。MusicXML、序列反向解码和插入 / 删除对齐尚未实现。

本地使用

直接用浏览器打开此 HTML，无需联网。点击播放后开启音频；切到后台会暂停。项目保存为 JSON 文件，包含两条原始输入和参数。序列上限 100,000 个符号；WAV 单次预算 64 MB，SVG 单次最多 2,048 个位置，可用导出范围分段保存。

快捷键：时间轴内 ← / → 选择位置，Home / End 到首尾，空格播放 / 暂停。
